# NRD Studio

**NotRealDaksh (NRD)** is a mobile-first AI media creation and publishing workspace.

## Product direction

NRD brings together original content workflows: planning, script and storyboard preparation, media assets, voiceover and subtitle production, video assembly, and platform publishing workflows.

The product is designed mobile-first, with a simple interface for creators and a modular architecture that can grow without tying the project to a single paid AI provider.

## Principles

- Mobile-first, responsive experience.
- Open-source components with license checks before integration.
- Bring-your-own-provider credentials where external APIs are optional.
- Transparent usage, costs, permissions, and publishing limitations.
- Real working features over mock controls or demo-only screens.
- User review and approval before publishing by default.

## Current status

Repository foundation is being established. Feature completion will be documented as each workflow is implemented and tested.

## Planned modules

1. Workspace and channel management.
2. Content planner and script workspace.
3. Media library and asset preparation.
4. Voiceover, subtitles, and localization workflows.
5. Video assembly and export.
6. Publishing connections, scheduling, and post history.

## Security

Never commit API keys, OAuth secrets, access tokens, or personal credentials. Use environment variables and server-side secret storage for integrations.
